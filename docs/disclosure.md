# AI-usage disclosure

This file is the running record of how you used AI tools in this project: what you
delegated to them, and where your own judgement stepped in. Add **one line at the end
of every exercise session**, commit it, and keep the file to the end of the course.

Each line says three things:

1. the week;
2. what you used an AI tool for (which tool and model, and what it did);
3. how you checked the result, and what you kept, changed or rejected.

If you used no AI tool in a session, say so in the line.

The format, with an example (copy the shape, not the words):

```text
- WNN · <tool and model> · Used for: <what it did> · Checked by: <how you checked it; what you changed or rejected>
- W02 · none · Used for: nothing; I made the changes myself · Checked by: reading the files on GitHub after the merge
```
